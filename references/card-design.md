# 多页读书卡视觉与交互规范

## 核心原则

- 只为手机设计，以 393 × 852 CSS px 为基准，同时覆盖 360–430px 宽的常见手机屏幕。
- 页面占满 `100vw × 100dvh`，并提供 `svh` / `vh` 回退；不制作桌面手机模型、不设置桌面最大宽度，也不增加外围装饰。
- 页面优先在首屏建立完整视觉重心，但允许内容区向下滚动。不得为了强行一屏而缩小字号、压扁间距或删掉关键解释。
- 页数由内容决定，不固定为 4、10 或 12 页。
- 第 1 页是唯一可显示封面、书名和作者的页面；第 2 页以后只呈现知识内容。
- 主要交互为左右滑动，辅以底部圆形上一页 / 下一页按钮、始终显示的“当前页 / 总页数 · 当前栏目”与顶部阅读进度；窄屏也不能隐藏总页数。
- 单文件、零外部依赖，封面图以 data URI 内嵌，可直接在手机浏览器打开。

## 视觉基因

- 页面底色：暖纸色 `#F7F4EB`，正文为墨黑 `#26281F`。
- 强调色优先采用 `book.cover_color`，缺省使用朱砂红；进度、序号、重点线条统一取该颜色。
- 大标题与引文使用中文宋体/衬线字体回退；正文使用系统黑体；页码和元数据可使用等宽字体。
- 整体是克制的杂志编辑感：大量留白、细分隔线、斜体大序号和清晰层级。
- 不使用大面积彩色内容面板、阴影堆叠或桌面端卡片外壳。
- 底部导航采用轻透明纸色，顶部阅读进度使用 2px 细线。

## 第一页

- 页首只显示 `READER'S CARD` 与细线；不展示出版年份或版本年份。
- 书籍封面居中、轻微旋转；有真实封面时内嵌图片，没有时使用书名排版式封面回退。
- 封面下依次显示书名、可选短注/英文名、作者、概览、阅读主张与 3 项阅读收获。
- 3 项阅读收获必须恰好为三项，严格沿用模板中的纵向列表：两位斜体序号、单行文字与细分隔线，不改成三列卡片。
- 底部提供“开始阅读”按钮、知识卡数量和“左右滑动翻页”提示。
- 第一页应能单独用于演示或截图：视觉重心明确、信息层次完整、第一眼即可理解本书价值。
- 不显示章节进度、评分、收藏、章节目录或“继续阅读”等旧模块。

## 后续页

- 页首使用页码、短线与栏目名建立固定阅读秩序，下面是页面标题。
- 内容页支持四种固定结构：`statement`、`list`、`steps`、`quote`。
- 陈述页突出核心判断；列表页用大序号组织最多 4 项；步骤页用圆点与连线组织最多 3 步；引文页使用大号衬线引文。
- 不重复封面、书名、作者或书籍页脚。
- 不显示“转述”“推读”等内部标签，也不显示证据、章节出处、网址、资料边界或来源页。
- 最后一页的下一页按钮显示完成状态。

## 页面容量

- 内容标题建议不超过 22 个汉字。
- `statement` 最多 3 段，每段尽量控制在 70 个汉字以内。
- `list` 最多 4 项；`steps` 最多 3 项；超出时拆成新页。
- 表格必须改为纵向条目或拆页。
- 内容略超首屏时允许自然向下滚动；若单页包含多个主题或需要连续滚动很长距离，则拆页。
- 底部必须预留导航空间，滚动到末尾时任何正文、强调框或列表都不得被导航遮挡。

## 交互与可访问性

- 支持真实手指拖动、快速轻扫、上一页 / 下一页按钮、方向键以及 `Home / End`。
- 到达第一页或最后一页时禁用对应按钮；最后一页明确显示完成。
- 非当前页同步更新 `aria-hidden` 与 `inert`，页码和页面说明通过可读状态更新。
- 每次打开从封面开始，不记忆上次页码。
- `prefers-reduced-motion` 时关闭大幅动画。
- 必须分别在 360 × 640、393 × 852、430 × 932 CSS px 下检查：短页面不产生多余滚动，长页面可以顺畅滚到底部；无横向越界，交互可用，控制台无错误或警告。

## 固定源码

[reading-card-template.html](reading-card-template.html) 由用户提供的 `reading-card-peak.html` 适配而来，是深度萃取模式唯一视觉模板。生成时只替换其中的 `__BOOK_DATA__` 数据占位符；不要重写 CSS、DOM 骨架或翻页逻辑。需要修改全局样式时，先修改模板，再用至少两本不同内容密度的书进行回归检查。
